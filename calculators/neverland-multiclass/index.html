Neverland Multi-Class Pricing Model

A Neverland-specific view of the proposed session-based pricing structure: low class counts stop receiving discount, committed students are still rewarded, and the high end replaces unlimited enrolment with a tiny extra commitment per class.

1Client Summary · What Changes

This is the simple story: the platform uses a whole-enrolment percentage by eligible class count, but the high-end result behaves like each extra class only adds a small amount.

1-5 classes
0%
Families pay normal class fees. The discount is removed for low-load enrolments.
6-7 classes
10-20%
The reward starts only once the student is making a meaningful commitment.
8+ classes
5%
Each extra class adds only a small amount, instead of becoming unlimited.
How the platform applies it

The platform counts the student's eligible classes, selects the matching per-student unit field, then applies one percentage across the eligible session tuition stack.

For6Units = 10 and For7Units = 20. From For8Units onward, the percentages are equivalent whole-stack discounts that make each additional class add about $8.50 at the example fee.

What the platform calculates

All eligible tuition × Class-count discount % = Family term fee

The discount percentage applies to the whole eligible tuition stack for that student. At 8 classes, 29.375% is applied to all 8 eligible class charges. It is not 95% off the 8th class only inside the platform.

What the family experiences

The high-end tiers are designed so the total payable behaves like each additional class adds only a very small amount. That is a marketing explanation of the outcome, not the calculation method.

Example: 8 × $170 = $1,360 gross. The platform applies a 29.375% whole-stack discount, so the family pays $960.50. That is the same total as saying the 8th class only added $8.50.

2Studio Marketing Direction

Use plain outcome language publicly. Keep the internal percentage table for fee setup and staff explanation, not as the main parent-facing story.

Recommended wording

Multi-class discounts are applied to a student's eligible tuition once they reach the higher class-count tiers. Families taking one to five classes pay normal class fees. From six classes onward, the discount increases, and from eight classes onward each extra class only adds a small amount to the term fee.

This rewards committed dancers while keeping every class enrolment intentional.

Avoid this wording

Your 8th, 9th and 10th classes are 95% off.

That sounds like a marginal discount on individual class lines. The platform does not calculate it that way. It applies one class-count discount percentage across the student's eligible tuition.

Fee guide version

The multi-class discount is based on the total number of eligible classes a student takes in the term. Once the student reaches a discount tier, the tier percentage is applied to their eligible tuition total.

Staff explanation

Tell families the total term fee reduces as their class count increases. Do not describe individual classes as being 95% off; describe the high-end tiers as a small additional commitment per extra class.
