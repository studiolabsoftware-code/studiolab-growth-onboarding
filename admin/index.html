Where the secret keys live

Add these in the Supabase dashboard under Edge Functions → Secrets (or via supabase secrets set). The frontend never reads them.

  • STRIPE_SECRET_KEY_TEST — your sk_test_… key
  • STRIPE_SECRET_KEY_LIVE — your sk_live_… key
  • STRIPE_WEBHOOK_SECRET_TEST — the whsec_… from your test webhook endpoint
  • STRIPE_WEBHOOK_SECRET_LIVE — the whsec_… from your live webhook endpoint
